# Holberton School – SQL Warrior

## Présentation

Ce repository regroupe mes exercices et travaux pratiques réalisés dans le cadre de ma formation en Software Engineering chez Holberton School.

Le projet SQL Manga permet de découvrir et de pratiquer le langage SQL à travers la gestion d'une base de données relationnelle consacrée à une boutique de location de mangas.

## Objectifs pédagogiques

- Comprendre le fonctionnement d'une base de données relationnelle.
- Manipuler des tables et leurs relations.
- Interroger des données avec SQL.
- Filtrer et trier des résultats.
- Utiliser des fonctions d'agrégation.
- Réaliser des jointures entre plusieurs tables.
- Insérer, modifier et supprimer des données.

## Environnement technique

- **MySQL 8.0** : système de gestion de base de données relationnelle.
- **Docker** : environnement d'exécution des services.
- **Docker Compose** : orchestration des conteneurs.
- **phpMyAdmin** : interface graphique d'administration MySQL.
- **Ubuntu / WSL2** : environnement de développement.

## Projet SQL Manga

La base de données `tp_manga` comprend sept tables :

- `clients`
- `factures`
- `genres_manga`
- `mangakas`
- `mangas`
- `table_location`
- `types_location`

Les exercices sont organisés dans le dossier `sql_manga`.

## Objectif personnel

Développer progressivement mes compétences en SQL, comprendre la logique des bases de données relationnelles et apprendre à manipuler des données de manière structurée.
